# Трекер Калорий и Тренировок (Calorie & Workout Tracker)

## Описание
Мобильное приложение для отслеживания потребляемых калорий и планирования тренировок. Приложение помогает пользователям достигать своих фитнес-целей, предоставляя удобные инструменты для контроля питания и физической активности.

## Основные возможности (Планируемые)
* **Дневник питания:** Удобный поиск и добавление продуктов, расчет КБЖУ (калории, белки, жиры, углеводы).
* **План тренировок:** Создание индивидуальных программ тренировок, отслеживание прогресса, запись подходов и весов.
* **Аналитика:** Графики изменения веса, потребления калорий и активности за выбранный период.
* **Личный профиль:** Установка целей (похудение, набор массы, поддержание), учет параметров тела.
