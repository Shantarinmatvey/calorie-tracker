## Описание
Мобильное Android-приложение для отслеживания потребляемых калорий, КБЖУ, веса и планирования тренировок. Приложение разработано с использованием современного стека технологий Android (Jetpack Compose, Room) и включает в себя интеграцию с **Google Gemini AI** для автоматического распознавания еды по фотографии.

## Основной функционал

### 1. Дневник питания и подсчет калорий
* **Учет КБЖУ:** Добавление приемов пищи с указанием калорий, белков, жиров и углеводов.
* **ИИ-ассистент (Gemini):** Умное распознавание еды по фото. Просто сделайте снимок, и Gemini определит блюдо и его примерную пищевую ценность.
* **Отслеживание лимитов:** Установка суточной нормы калорий и визуальный прогресс-бар ее выполнения.
* **Агрегированная статистика:** Просмотр суммарного потребления калорий за день.

### 2. План тренировок
* **База упражнений:** Добавление собственных упражнений, указание рабочих весов, количества подходов и повторений.
* **Поддержка упражнений со своим весом:** Автоматическая синхронизация веса тела (Bodyweight) с текущим весом пользователя в журнале.
* **Программы тренировок:** Создание планов тренировок и назначение упражнений по дням недели.
* **Отслеживание выполнения:** Отметка выполненных упражнений в день тренировки.

### 3. Календарь и статистика
* Удобный календарь для навигации по прошедшим дням.
* Визуальная индикация выполнения лимита калорий в календаре (красные/зеленые точки).
* Возможность просмотра дневника питания и тренировок за любую выбранную дату.

### 4. Трекинг веса
* Добавление записей о текущем весе (синхронизируется с датой).
* Отображение истории изменения веса.
* Динамическое использование последнего внесенного веса для расчета нагрузок в упражнениях со своим весом.

## Технологический стек
* **Язык:** Kotlin
* **UI Framework:** Jetpack Compose
* **Архитектура:** MVVM (Model-View-ViewModel)
* **База данных:** Room (SQLite)
* **Асинхронность:** Coroutines & Flow
* **Сеть/API:** OkHttp3 (для работы с Gemini API)
* **AI Интеграция:** Google Gemini 3.5 Flash API

## Структура проекта
* `data/` — Слой данных: Сущности Room (`CalorieEntry`, `WeightEntry`, `Exercise`, `TrainingPlan` и др.), DAO (`TrackerDao`), База данных (`AppDatabase`), Репозиторий (`TrackerRepository`).
* `ui/` — Пользовательский интерфейс (Jetpack Compose): Главный экран `TrackerAppUI`, экраны дневника, тренировок, календаря, веса. Интеграция Gemini (`GeminiFoodHelper`).
* `viewmodel/` — Бизнес-логика и управление состоянием: `TrackerViewModel`.
* `theme/` — Цветовые схемы, типографика, константы дизайна.

## Инструкция по запуску

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Shantarinmatvey/-.git
   ```
2. Откройте проект в **Android Studio**.
3. **Настройка Gemini API (Обязательно для функции распознавания еды):**
   * Получите API-ключ на сайте [Google AI Studio](https://aistudio.google.com/app/apikey).
   * Откройте файл `local.properties` (или создайте его в корневой папке проекта, если его нет).
   * Добавьте строку с вашим ключом:
     ```properties
     GEMINI_API_KEY=ваш_секретный_ключ_здесь
     ```
4. Соберите проект (Sync Project with Gradle Files).
5. Запустите приложение на эмуляторе или реальном Android-устройстве.
